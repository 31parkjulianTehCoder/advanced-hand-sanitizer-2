# nullpoint
## Inspiration
People get hacked, scammed, and get their data stolen every day. Some people believe that the solution to this problem is to build "protection" tools, trying to detect these actions and stop them while it's happening. We believe the solution to this problem is education, not protection.
## What it does
Nullpoint offers free courses that educate users about these specific topics, such as avoiding malware or malicious bots. It gamifies the experience via hearts, points, and streaks.
## How we built it
Nullpoint was made using React and Javascript. No artificial intelligence was used in programming the app.
## Challenges we ran into
A challenge we ran into was making the courses quick yet challenging. The courses needed to effectively teach the user while not taking too long to complete.
